# Code review notes

Ниже — что было найдено при ревью предыдущей версии и что исправлено.

## Исправлено

1. **Падение процесса через `panic` в runtime-путях**
   - Было: `panic` при ошибках конфига, backend URL и старта сервера.
   - Стало: аккуратное логирование + `os.Exit(1)`.

2. **Host matching был чувствителен к регистру и порту**
   - Было: `Host` сравнивался «как есть».
   - Стало: нормализация `host` (lowercase + срез порта).

3. **Health-check не «дочитывал» body ответа**
   - Было: просто `Close()`.
   - Стало: `io.Copy(io.Discard, resp.Body)` перед `Close()`.

4. **Не хватало валидации части конфиг-параметров**
   - Добавлена `Validate()` для лимитов/таймингов/обязательных backend полей.

5. **Покрытие тестами host routing-case**
   - Добавлен тест на `EXAMPLE.com:443` для backend с `example.com`.

## Что оставлено осознанно

- JSON-конфиг оставлен простым, без внешних зависимостей.
- Метрики пока базовые (без Prometheus формата) — это отдельная задача.
